# Design Brief — landing page hero (sample)

This is a sample brief so `promptsmith.py` can run end-to-end without a personal
brain configured:

```bash
python3 scripts/promptsmith.py --task "build the hero section" \
  --brief-file examples/sample-brief.md --out-dir /tmp/promptsmith-demo
```

## Palette

- Background: near-black neutral (#111113)
- Text: warm off-white (#F5F1E8)
- One accent only: amber (#D9A441), used sparingly for the primary action

## Mood

- Calm, confident, editorial — generous whitespace, large readable type
- Motion earns its place: one entrance transition max, no ambient animation

## DO

- Lead with a single concrete claim a first-time visitor can verify
- Make the primary action obvious within one screen height
- Use real content in mockups, never lorem ipsum

## DON'T

- Don't use neon gradients or glassmorphism panels
- Don't autoplay video or animate on scroll
- Don't add a second accent color
- Never present placeholder metrics as real results

## References

- Editorial landing pages with strong typographic hierarchy
- Product pages that show the actual product state, not marketing renders
